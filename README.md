## Description

I developed this site for a custom bakery business specializing in personalized cakes for any occasion. The site features a gallery of sample cakes, customer reviews, and a consultation booking system to help customers place orders.

### Recent Updates

**Redesign & Rebrand:**
- Complete visual redesign with a modern, warm color palette (peaches, creams, and browns)
- Rebranded from "Nando's Cakes" to "Sweet Dreams Bakery"
- Mobile-first responsive design with improved accessibility and contrast
- CSS-based animations using `react-intersection-observer` for scroll-triggered effects
- Redesigned FAQ section with accordion-style layout
- Gallery-style Sample Cakes page showcasing all available cakes
- New Reviews page displaying all customer reviews in a flat list format
- Enhanced About page with detailed baker information, experience, and working hours

**Next.js Migration:**
- Migrated from Create React App to Next.js 15.1.3
- Implemented Next.js Pages Router architecture
- Updated routing from React Router to Next.js routing
- Optimized image handling using Next.js static file serving

**New Features (In Progress):**
- Admin login system with simple password authentication
- Admin panel for content management (coming soon)
- Planned integration with Supabase for database management
- Planned Cloudinary integration for image storage
- Admin capabilities will include:
  - Managing sample cake images (add/delete, sorted by upload date)
  - Managing FAQs (add/edit/delete)
  - Updating working hours and contact information
  - Managing "What I Bake" items
  - Editing baker introduction text
  - Deleting customer reviews
- Public review submission form (coming soon)

## How To Use

### Installation

- Fork/Clone Repo
- Cd into project folder
- `npm install`
- `npm run dev` (for development)
- `npm run build` (for production build)
- `npm start` (to run production build)
